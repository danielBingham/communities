## [Read Post](documentation/testing/test-cases/Post/read.md)

Cases covering reading posts and post visibility permissions.

### Pre-requisites

- [ ] User1 has been created.
- [ ] User2 has been created.
- [ ] User3 has been created.

### Smoke Tests

- [ ] As a user, I should be able to see a public post.
- [ ] As a user, I should be able to see my friend's private post.
- [ ] As a user, I should not be able to see a stranger's private post.

### Full Regression

- [ ] As a user, I should get a 404 Not Found for a post that doesn't exist.
- [ ] As a user, I should get a 404 Not Found for a post that I can't view.
