# Mobile

The iOS and Android apps: the web client wrapped by Capacitor, with
plugins for native features, updated live between store releases.
Releasing the apps to the stores is done by maintainers.

**Code:** `capacitor.config.js`, `ios/`, `android/`, `assets/`,
`web-application/client/`

| File | Read it when |
| ---- | ------------ |
| [capacitor.md](capacitor.md) | Changing the Capacitor configuration, the native projects, or icons and splash screens. |
| [native-features.md](native-features.md) | Using a native feature (push, secure storage, deep links, ...) or adding a plugin. |
| [live-updates.md](live-updates.md) | Working out whether a change reaches the apps without a store release. |
| [running-the-apps.md](running-the-apps.md) | Building and running the apps yourself. |
