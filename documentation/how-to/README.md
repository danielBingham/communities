# How To

Step-by-step recipes for common changes. Each is a checklist that links to
the docs for every layer it touches.

| File | Read it when |
| ---- | ------------ |
| [add-an-entity.md](add-an-entity.md) | Adding a new kind of thing to store and show, through every layer. |
| [add-an-api-endpoint.md](add-an-api-endpoint.md) | Adding a route and controller method. |
| [add-a-database-migration.md](add-a-database-migration.md) | Changing the schema or migrating data. |
| [add-a-feature-flag.md](add-a-feature-flag.md) | Putting a change behind a flag. |
| [add-a-worker-job.md](add-a-worker-job.md) | Moving work into a background job on a new queue. |
| [add-a-notification.md](add-a-notification.md) | Notifying users of something new. |
| [add-a-real-time-event.md](add-a-real-time-event.md) | Pushing a new kind of event to clients as it happens. |
| [add-a-page.md](add-a-page.md) | Adding a page to the client. |
| [add-a-configuration-value.md](add-a-configuration-value.md) | Adding a setting the apps read from configuration. |
| [move-validation-to-a-schema.md](move-validation-to-a-schema.md) | Moving an entity from the deprecated validators to a Schema. |
