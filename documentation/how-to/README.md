# How To

the code from one end. For anything else, find a similar piece of code and
follow it; [Architecture](../architecture/README.md) says where to look.

| File | Read it when |
| ---- | ------------ |
| [add-a-feature-flag.md](add-a-feature-flag.md) | Putting a change behind a flag, or trying one locally. |
| [add-a-database-migration.md](add-a-database-migration.md) | Changing the schema or migrating data. |
| [add-a-configuration-value.md](add-a-configuration-value.md) | Adding a setting the apps read from configuration. |
| [add-a-worker-job.md](add-a-worker-job.md) | Moving work into a background job on a new queue. |
| [add-a-notification.md](add-a-notification.md) | Notifying users of something new. |
